# OpenClient

OpenClient is a Minecraft client focused on performance, HUD customization, and small utilities that make everyday gameplay more convenient.

## Modules

Modules currently include:

- FPS
- Sprint Toggle
- Coordinates
- Biome
- Ping
- Armor Status
- Potion HUD
- Keystrokes
- Target HUD
- Totem Counter

More modules may be added over time.

## Building

Clone the repository and build the project with Gradle:

```bash
git clone https://github.com/mrkaktusik52/OpenClient
cd OpenClient
./gradlew build
```
